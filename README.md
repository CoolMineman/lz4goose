# lz4goose

An incomplete attempt at verifying a Go implementation of lz4 I did for [CS 839: Systems Verification in Fall 2025](https://tchajed.github.io/sys-verif-fa25/). Also contains some work on a toy run-length encoder. For more information read the [Project Report I submitted in December](./839%20Project%20Report%20Ben%20Friedl.pdf).
